1) المتطلبات العامة

  • Node.js 20+ و npm
  • JDK 17 (للبناء المحلي لأندرويد)
  • Android SDK عبر Android Studio (للبناء المحلي)
  • حساب Google Play Console (رسوم تسجيل لمرة واحدة)
  • حساب Apple Developer (99$/سنة)
  • حساب Expo — للبناء السحابي لـ iOS

Install dependencies once: cd mobile_app_new && npm ci

2) بناء نسخة إنتاج أندرويد محلياً (AAB)

Google Play يتطلب ملف AAB (Android App Bundle) وليس APK للإنتاج.

الخطوة أ — إنشاء مفتاح التوقيع (مرة واحدة فقط)

احفظ ملف الـ keystore وكلمات المرور في مكان آمن. فقدانها يمنعك من تحديث التطبيق على المتجر.

cd mobile_app_new
npm run keystore:generate

ثم انسخ المثال وعدّل القيم:

copy android\keystore.properties.example android\keystore.properties
# عدّل المسارات وكلمات المرور في keystore.properties

لطباعة SHA-1 (مطلوب لـ Google Sign-In و Firebase):

npm run keystore:sha1

الخطوة ب — التأكد من google-services.json

يجب وجود mobile_app_new/google-services.json وandroid/app/google-services.json لتسجيل Google وإشعارات FCM.

الخطوة ج — تشغيل البناء

cd mobile_app_new
npm run build:android:production

This runs: version bump → icon generation → expo prebuild → gradle bundleRelease

مخرجات البناء: 
android/app/build/outputs/bundle/release/app-release.aab

هذا الملف الذي ترفعه إلى Google Play.

الأمرالغرضالمخرج
npm run build:android:release اختبار محلي / توزيع مباشر APK
npm run build:android:production Google Play AAB
npm run eas:build:production:android بناء سحابي (بديل) AAB من EAS

3) الرفع إلى Google Play Console

أول مرة — إنشاء التطبيق

  1. افتح Play Console → إنشاء تطبيق
  2. اسم التطبيق: NUX
  3. اختر اللغة الافتراضية والنوع (تطبيق / ألعاب) والفئة المناسبة
  4. أكمل إعداد التطبيق من القائمة الجانبية:
    • سياسة الخصوصية (رابط: https://nuxapp.de/privacy أو صفحتكم)
    • إعلان الإعلانات، التصنيف العمري، الجمهور المستهدف
    • أمان البيانات (Data safety)
    • متجر التطبيق: الوصف، لقطات شاشة، أيقونة 512×512

رفع الـ AAB

  1. من القائمة: الإصدار → الإنتاج (أو اختبار داخلي للتجربة أولاً)
  2. إنشاء إصدار جديد
  3. رفع → اختر app-release.aab
  4. أدخل ملاحظات الإصدار (ما الجديد في هذا الإصدار)
  5. راجع التحذيرات (التوقيع، الأذونات، targetSdk)
  6. مراجعة الإصدار → بدء النشر للإنتاج
توقيع التطبيق (App signing)

عند أول رفع، Google Play يطلب تفعيل Play App Signing. ارفع مفتاح التوقيع المحلي (upload key) أو دع Google تديره حسب الخيار المعروض.

إذا بنيت محلياً بـ keystore خاص بك، سجّل SHA-1 من npm run keystore:sha1 في Firebase Console و Google Cloud (OAuth Android client).

مسار الاختبار الموصى به

  1. اختبار داخلي — أضف بريد المختبرين، ارفع AAB، ثبّت عبر رابط الاختبار
  2. اختبار مغلق — مجموعة أكبر
  3. الإنتاج — بعد التأكد من الاستقرار

4) بناء iOS للإنتاج عبر EAS

بناء iOS يتطلب macOS و Xcode محلياً؛ الطريقة المعتمدة هنا هي EAS Build على خوادم Expo.

الخطوة أ — تسجيل الدخول ومتغيرات البيئة

cd mobile_app_new
npm run eas:login

تأكد من ضبط الأسرار على Expo → Project → Environment variables (أو eas env:create):

  • EXPO_PUBLIC_API_URL = https://back.nuxapp.de/api
  • EXPO_PUBLIC_WEBSITE_URL = https://nuxapp.de
  • مفاتيح Stripe و Google و Maps حسب EAS_BUILD.md

الخطوة ب — الشهادات (أول مرة)

عند أول بناء iOS، EAS يسأل عن الشهادات. اختر Let EAS handle credentials ما لم تكن لديك شهادات جاهزة.

تأكد من موافقات Apple Developer واتفاقيات App Store Connect (Agreements, Tax, Banking).

npm run eas:credentials

الخطوة ج — تشغيل البناء

cd mobile_app_new
npm run eas:build:production:ios

Equivalent: npx eas build --platform ios --profile production

انتظر حتى يكتمل البناء على expo.dev. ستحصل على ملف .ipa جاهز للرفع.

ملف التعريف production في eas.json
  • buildType: iOS device build (ليس simulator)
  • autoIncrement: يزيد رقم البناء تلقائياً
  • Bundle ID: de.nuxapp.app

5) الرفع إلى App Store Connect

الطريقة أ — EAS Submit (موصى بها)

بعد نجاح البناء:

cd mobile_app_new
npm run eas:submit:production:ios

Or: npx eas submit --platform ios --profile production

اتبع المطالبات: اختر آخر بناء من EAS أو مسار ملف .ipa، وأدخل Apple ID و App-specific password إن طُلب.

الطريقة ب — يدوياً عبر App Store Connect

  1. حمّل Transporter من Mac App Store (أو Xcode → Organizer)
  2. حمّل ملف .ipa من صفحة البناء على expo.dev
  3. ارفعه عبر Transporter إلى App Store Connect

إعداد التطبيق في App Store Connect

  1. App Store Connect → تطبيقاتي → + إذا لم يُنشأ التطبيق
  2. Bundle ID: de.nuxapp.app (يجب أن يطابق Xcode/EAS)
  3. أكمل: لقطات الشاشة (iPhone 6.7" و 6.5" على الأقل)، الوصف، الكلمات المفتاحية، رابط الدعم والخصوصية
  4. من TestFlight: اختبر البناء قبل الإنتاج
  5. من App Store → إصدار جديد: اختر البناء المرفوع، أجب على استبيان التشفير، أرسل للمراجعة
قبل المراجعة
  • تأكد من عمل تسجيل الدخول و Google Sign-In على جهاز حقيقي
  • أذونات الموقع والكاميرا موضحة في Info.plist
  • حساب تجريبي للمراجع إن كان التطبيق يتطلب تسجيل دخول

6) استكشاف الأخطاء الشائعة

المشكلةالحل
فشل البناء المحلي — keystore.properties شغّل npm run keystore:generate وانسخ keystore.properties.example
Google Sign-In لا يعمل على الإصدار أضف SHA-1 من npm run keystore:sha1 في Firebase و Google Cloud
EAS iOS — pod install failed راجع app.config.js و EAS_BUILD.md (إعدادات extraPods)
Apple — agreements pending App Store Connect → Agreements, Tax, and Banking
رفض المراجعة — crash عند الفتح اختبر بناء production على جهاز حقيقي؛ تحقق من متغيرات البيئة على Expo
رسالة شبكة بالعربية تم توحيدها بالإنجليزية: No internet connection. Please check your network and try again.

مرجع سريع للأوامر

# Android — Google Play (محلي)
npm run build:android:production

# iOS — بناء سحابي
npm run eas:build:production:ios

# iOS — رفع إلى App Store
npm run eas:submit:production:ios

# معاينة APK للاختبار
npm run eas:build:preview:android
